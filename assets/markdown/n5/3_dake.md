# Catatan Tata Bahasa Jepang: だけ (dake)

**Arti:** Hanya, cuma, saja, atau "sebisa/sebanyak mungkin".

---

## 1. Rumus Penggunaan

Tempelkan **だけ (dake)** di belakang kata-kata berikut:
* **Kata Kerja (Bentuk Kamus)** + だけ
* **Kata Benda** + だけ
* **Kata Sifat-na** + な (na) + だけ
* **Kata Sifat-i** + だけ

---

## 2. Contoh Kalimat

### Makna 1: Cuma / Hanya / Saja
* 一人**だけ**。(Hitori dake) -> *Cuma satu orang / Sendirian aja.*
* ただ一つ**だけ**ある。(Tada hitotsu dake aru) -> *Cuma ada satu.*
* ほしいものはこれ**だけ**。(Hoshii mono wa kore dake) -> *Barang yang aku mau cuma ini doang.*

### Makna 2: Sebisa mungkin / Setidaknya
* 私はできる**だけ**金を借りないようにしている。(Watashi wa dekiru dake kane o karinai you ni shite iru) -> *Sebisa mungkin aku berusaha untuk tidak meminjam uang.*
* いくら何でも15人**だけ**は来るだろう。(Ikura nan demo juugo nin dake wa kuru darou) -> *Walau bagaimanapun, setidaknya 15 orang pasti akan datang.*
